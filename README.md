# موقع حضانة براعم

موقع عربي ثابت (HTML / CSS / JavaScript)، جاهز للنشر مجانًا عبر GitHub Pages أو على استضافة Hostinger عادية.

## محتويات المشروع

- `index.html` الصفحة الرئيسية ومحتوى الموقع.
- `assets/css/style.css` التصميم والألوان والتجاوب مع الجوال.
- `assets/js/main.js` قائمة التنقل للجوال.

## قبل النشر

1. غيّر الاسم المؤقت «براعم» والعبارات التجريبية داخل `index.html`.
2. استبدل رقم واتساب `201000000000` برقم الحضانة مع كود الدولة، بدون `+`.
3. عدّل رقم الهاتف والعنوان والبريد الإلكتروني وروابط حسابات التواصل.
4. الصور الحالية تجريبية من Unsplash. يمكن استبدالها بصور الحضانة وكتابة مسارات الصور مثل `assets/images/hero.jpg` داخل `index.html`.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub، مثل `baraem-nursery`.
2. ارفع كل محتويات هذا المجلد إلى جذر المستودع، بحيث يكون `index.html` في المستوى الأول.
3. افتح **Settings → Pages**.
4. تحت **Build and deployment** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
5. انتظر اكتمال النشر، وسيظهر رابط الموقع في صفحة Pages. عادةً يكون بالشكل `https://USERNAME.github.io/baraem-nursery/`.

## ربط دومين خاص

من **Settings → Pages → Custom domain** أدخل الدومين الذي تملكه واتبع تعليمات DNS التي يعرضها GitHub. لا تغيّر سجلات الدومين قبل معرفة الإعدادات المطلوبة من مزود الدومين.

## التعديل لاحقًا

عدّل النصوص والروابط في `index.html`، والألوان والتنسيق في `assets/css/style.css`. ارفع التعديلات إلى المستودع، وسيُحدّث GitHub Pages الموقع بعد اكتمال النشر.

هذه نسخة ثابتة بلا لوحة تحكم؛ تعديل المحتوى يتم من ملفات المشروع ورفعه مجددًا.
